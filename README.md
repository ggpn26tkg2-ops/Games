# NEON ARCADE

Three original browser games for touch-first play: `gta.html` (JOY RIDE, fully unlocked), `baja.html` (BAJA BLAST BRAPTOR, WebGL), `orange.html` (CRAZY CAT LADY, WebGL). The root index is the arcade menu. `v1.html` remains an unlisted legacy build. Local saves stay under the original origin; Baja retains its previous save key. Orange has its own save key. Original procedural vehicle and character art; no uploaded reference photos. No external dependencies.

Gameplay tests use mocked browser and graphics APIs. Real Safari rendering, visual fidelity and frame rates require device testing. GitHub Pages publishes the main branch when configured.
